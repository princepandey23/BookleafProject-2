# BookLeaf — VS Code Commands

## Prerequisites
- Node.js v18+ installed
- npm installed

## Setup & Run

```bash
# 1. Navigate to backend folder
cd backend

# 2. Install dependencies
npm install

# 3. Set your Anthropic API key (required for AI email generation)
#    On Windows:
set ANTHROPIC_API_KEY=your_api_key_here
#    On Mac/Linux:
export ANTHROPIC_API_KEY=your_api_key_here

# 4. Start the server
npm start

# 5. Open in browser
#    http://localhost:3000
```
